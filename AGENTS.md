# Leerkrachtentools project conventions

## Writing style

- Do not use em dashes (`—`) or en dashes (`–`) in prose, comments, documentation, commit messages, or release titles. Use commas, colons, periods, or an ASCII hyphen-minus (`-`) for ranges.
- Do not use emojis anywhere in the repository: UI copy, docs, tests, commits, or release notes.
- GitHub release titles use the version number only (for example `v5.11.0`), consistent with earlier releases. Do not append a subtitle after a dash.
